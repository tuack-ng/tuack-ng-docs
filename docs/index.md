## Tuack-NG 是什么？

Tuack-NG（`Tuack New Generation`）是一套辅助 OI/ICPC 出题的工具包，旨在帮助出题人以更加便携的方式协作出题。

它涵盖了以下方面：

- 生成题面 PDF / Markdown
- 编写测试用例进行测试
- 使用 Std 和数据生成器生成数据
- 导出工程到 OJ 或评测机

同时，它也是 [Tuack](https://gitee.com/mulab/oi_tools/) 的精神继承者。

欢迎为这个项目提交贡献。
