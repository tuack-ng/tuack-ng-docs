title: 随机种子

---

## `.seed` 文件

`.seed` 文件位于 `data/` 或 `sample/` 目录下，JSON 格式：

```json
{"1": 12345678, "2": 87654321}
```

## 三种动作与种子的关系

| 动作    | 行为                                                 |
| ------- | ---------------------------------------------------- |
| `gen`   | 仅给尚无种子的测试点分配新种子，已有数据不会重新生成 |
| `regen` | 使用相同的种子重新生成所有数据点                     |
| `reset` | 丢弃所有旧种子，重新分配新种子并重新生成             |

> [!important]
> `.seed` 文件应纳入版本管理，以保证数据生成的可复现性。

## 注意事项

不建议手动修改 `.seed` 文件。如需强制重新生成所有数据（例如重造数据），请使用 `reset` 动作。
